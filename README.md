# Заказ продуктов — мини-приложение

Считает заказ продуктов по датам: выбираешь числа — приложение переводит их в дни цикла меню
(день 1 = 16.11.2026) и показывает список по разделам.

Открывается в браузере и внутри Telegram (Mini App).

Файлы:
- `index.html` — экран
- `calc.js` — расчёт (тот же, что в боте)
- `data.js` — меню, рецептуры, категории
